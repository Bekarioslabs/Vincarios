# ZEUS V1 Product Brief

## One-Sentence Product

ZEUS is a local Obsidian-vault assistant that helps users safely analyze, organize, connect, and update Markdown notes through visible, reviewable, reversible actions.

## Product Truth

- ZEUS is note-first, not agent-first.
- ZEUS complements Obsidian instead of replacing it.
- ZEUS works primarily with Markdown files.
- ZEUS should make vault organization easier, not become a general automation harness.
- AI suggests; the app validates, previews, backs up, logs, and executes.

## V1 User Promise

ZEUS helps users clean up and maintain their vault without hidden file access, cloud dependency, or blind autonomous edits.

## V1 Core Features

1. Open a vault and configure a vault profile.
2. Use local chat providers: LM Studio and Ollama.
3. Read Markdown notes and folders through explicit permissions.
4. Collect AI suggestions in a review module instead of one-action-at-a-time chat cards.
5. Preview every write with a diff before applying.
6. Create, update, insert into, move, rename, and archive Markdown notes safely.
7. Provide inbox/project/knowledge cleanup suggestions.
8. Use local embeddings V1-light for similar notes, link candidates, tag candidates, and folder candidates.
9. Create a new project through deterministic app logic.
10. Keep backups and audit logs for risky actions.

## Not V1

- Vision and image workflows.
- PDF/audio/video handling.
- Full plugin system.
- Trusted/Yolo mode.
- Cloud providers by default.
- Theme builder or Obsidian theme compatibility.
- Large autonomous vault cleanup.
- Complex automatic link repair after mass rename.
- Monetization/Patreon features.
- Complex external web research.
- Mobile version.
- Multi-window.
- Bundled chat LLMs.
- Specialized project dashboards.

## Success Criteria

- A non-technical Obsidian user can open a vault, let ZEUS inspect allowed notes, review suggestions, and apply selected changes with confidence.
- No risky write happens without preview, backup, and audit log.
- The codebase is small enough that a new developer can understand the main flow in one session.
