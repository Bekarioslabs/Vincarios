# vincarios v0.1.0-beta.1 - Historical Beta Draft

> Historical reference only. This beta draft was superseded by the source-only closure decision. It is not a published GitHub Release, an active release plan or an available EXE download. Do not execute its publication instructions. README and the source-archive checklist describe the current direction; no public executable is planned.

## Local-first Markdown workflows, under review

vincarios is a Windows desktop app for working with Markdown vaults through visible, reviewable actions. It complements Obsidian-style vaults without replacing Obsidian.

This public beta is for people who want to test local-first vault workflows and are comfortable reporting reproducible issues. Start with a copy of a vault or a dedicated test vault.

## Included in this beta

- Local vault browsing, Markdown Preview, Source Editor Light, Recent Files, Vault Home, and deterministic Search.
- Local-provider chat and provider-backed actions through LM Studio or Ollama.
- Explicit file and folder context, protected by Read permission.
- Similar Notes using local embeddings plus deterministic relevance signals.
- Reviewed note and project creation, whole-note updates, diffs, backups, stale-content checks, and audit logs.
- Vault-local Metadata, Embedding, and optional Full-text indexes.
- Light/Dark and built-in vault theme packs.

## Important beta boundaries

- Windows 10/11 only.
- The portable build is unsigned. Windows may show a SmartScreen warning; inspect the published checksum before running any downloaded build.
- A local provider is optional for browsing, Search, Preview, and indexes. Use LM Studio or Ollama for chat and provider-backed actions.
- Existing-note updates are reviewed whole-note proposals. Partial section editing is not included.
- No silent writes, trusted/yolo mode, cloud provider as the default workflow, plugin system, mobile app, or full Obsidian-plugin compatibility.

## Install

### Windows portable build

1. Download the portable `.exe` and its accompanying `.sha256.txt` file from this release.
2. In PowerShell, compare the published checksum with the downloaded file:

```powershell
(Get-FileHash .\vincarios-0.1.0-beta.1-portable.exe -Algorithm SHA256).Hash.ToLowerInvariant()
```

3. Start the executable and open a test vault or a copy of an existing vault.
4. For AI-backed workflows, configure a local LM Studio or Ollama provider in Settings.

### Build from source

```powershell
npm ci
npm run model:provision
npm start
```

For a portable build:

```powershell
npm run build:win
```
